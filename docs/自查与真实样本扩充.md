# 自查与真实样本扩充

2026年10月3日完成。项目已修复一批会导致漏提、错配期间或错误比较的问题，并新增四家公司共六份公开财报。这是可复现的小样本核对，不能据此声称所有财报的准确率为100%，也不能凭关注信号认定财务造假。

## 已发现并修复的问题

|问题|可能造成的结果|现在的处理|
|---|---|---|
|原表披露基期金额，模型却漏提|同比大量显示缺失|以核验过的本期金额确定同表对应列，再核验基期行列、单位、期间；不根据增长率反推金额|
|单季度、累计、年末和同期末混用|计算出形式正确但口径错误的增长率|核对完整起止日期和自然季度；时点余额不做累计差分，年末余额不充当上年同期末余额|
|跨页表头、调整前后合并列、金额换行解析不完整|数字被误拒绝或绑定到错误列|仅继承明确绑定的跨页表头；识别特定的调整前后列结构；只在同一个金额单元格内还原换行数字与负号|
|把营业总收入、归母净利润、境外准则金额当作目标金额|指标名称相似，但经济含义不同|存在独立营业收入分项时使用分项；合并净利润取独立总计行；只接受中国会计准则人民币数据|
|非经常性损益使用税前小计，或直接把归母减扣非当作披露值|税后归母口径错误，虚构原始披露|检查所得税、少数股东扣减后的明细合计；减法仅用于核对真实合计行，摘要缺失时保留证据不足|
|同公司同期的不同文件有冲突，或直接季度金额与累计差分冲突|上传顺序决定使用哪一个数字|汇总同公司同期记录并保留来源；冲突时停止计算，显示暂不可比较|
|有调整前后金额，但无法证明本期与基期口径对齐|混用未调整基期，或全部拒绝比较|需同一来源文件明确披露比较期间重述，再使用核验过的调整后基期；无证据则拒绝比较|
|会计变更段落被拆成多个文本块|真实引用被误判为不存在|允许同页原文中相邻、连续的引用块；跳过正文、倒序拼接、缺少引用和跨页拼接仍拒绝|
|标题、否定句与“没有重大影响”混淆|漏报已经发生的变化，或把标题当作变化|按明确实施的动作判断；没有重大影响不代表没有变更；补查明确已重述比较财报的原文句子|
|负现金流基期使用一般增长率或“亏损扩大”说明|数学表达和财务含义误导|保留负基期专门状态，不给普通增长率；现金流使用净流入、净流出说明，利润才使用盈亏说明|
|定向补查或批量模型调用中途失败|已经核验的金额被丢弃|保留已完成结果，并明确说明未完成范围；无任何可核验金额时不生成正常分析结论|

第一季度单季与1至3月累计具有完全相同的期间，程序允许这一特定等价；其他季度不能套用。三类关注规则仍优先评估年初累计口径。

本次还检查了密钥配置、日志、上传文件名和结果下载路径。密钥不进入界面、请求日志或配置对象的打印输出；模型错误提示使用本地定义的说明，不直接展示服务端响应。上传使用内容摘要和清理后的文件名，读取已保存样本结果限定在项目output目录并核对来源文件摘要。当前启动脚本只监听本机127.0.0.1。本次主要是财务逻辑与流程审查，未进行完整的网络安全渗透测试。

## 怎么复现

双击项目根目录“启动财报分析.cmd”。选择“真实财报分析”，点击“查看已核对的6份样本结果（不调用API）”，直接查看本次结果。也可以在“选择财报来源”中选择某家公司或全部六份，然后点击“开始分析”重新调用模型；新的提取结果可能不同，需再次运行核对脚本。

重新检查已经保存的最终结果，不调用模型：

```powershell
.\.venv\Scripts\python.exe scripts/verify_public_examples.py --result ".\output\20261003T122508Z_public_0b0c7447\result.json"
```

将两次原始真实模型运行按当前规则重新核验，也不调用模型：

```powershell
.\.venv\Scripts\python.exe scripts/rebuild_public_run.py --runs ".\output\20261003T092844Z_a27d24a4" ".\output\20261003T121104Z_3a592051"
```

该命令生成新的独立目录。再对新目录的result.json运行核对脚本；全部通过后，界面“查看已核对”按钮将指向新结果。

## 仍然存在的缺口

1. 扫描件没有OCR，超复杂表格和跨页文字段落仍可能解析不完整。无法核验的内容必须留空，不能填零。
2. 附注通过关键词选择部分页面，尚不能保证全文覆盖。会计变化仍有不少“证据不足”，这不代表没有变化；华虹半年摘要本身也缺资料。
3. 会计政策等语义主要依赖模型提取和保守的文本规则。程序能证明引用和金额来自原文，不能充分证明所有语义判断正确，也没有证明对恶意财报提示注入完全免疫。
4. 当前主要适配中国会计准则、人民币、普通企业报表。银行、保险、外币、境外准则需要单独适配；尚未建立行业基准。
5. 非经常性损益20%、现金流/正合并利润0.80是项目启发式阈值，不是监管标准，也没有用足够多的独立数据校准。负利润时当前现金转化规则显示不适用，缺少专门的亏损企业分析。
6. 当前异常规则优先分析累计口径，尚未对每个单季度独立生成异常信号。半年摘要缺少净利润也会限制单季利润推导；时点指标的季度比较仍需要对应季度末资料。
7. 这六份资料已用于排查和修复，应视为开发样本。还需要未参与调试的公司、年度与行业作为独立评测集，再统计字段和引用准确率、异常信号精确率与召回率。当前核对没有覆盖全部指标，也不构成财务造假识别准确率。

优先补齐的方向是：添加全文半年报和完整可比期间，制作独立人工标注集，再根据错误统计完善解析与规则。之后再扩展OCR和行业适配。这样能先改善结果的可验证程度。
