# 财报核验工作台：评审复现说明

开发更新：2026年10月10日。团队：北京林业大学·创新者联盟队。

## 启动与输入

1. 在项目目录运行“首次安装.cmd”，已有环境可直接运行“启动财报分析.cmd”。组员默认浏览器端口8501；作者开发预览8503。
2. 选择“成果展示”，已有六份公开财报（四家公司）和两份伊利2024/2025完整年报。切换样本不调用API。
3. 在“真实财报分析”上传可复制文本的中文人民币PDF。建议同一公司多个期间；单次1—6份，每份不超过30MB。真实模式从本地.env读取密钥，模型只接收检索片段。

## 现场演示顺序

- 分析总览：金额、期间及关注信号；亿元仅为显示，精确元金额仍保留。
- 期间比较：累计、单季及合并/母公司分开；Q2=半年−Q1、Q3=前三季−半年。跨零及小基期保留绝对变动额，不输出常规增长率。
- 原因与明细：公司原文解释、非经常性项目、税和少数股东调整，以及净利润到经营现金流调节。合计不闭合时保留残差。
- 原文核对：定位来源PDF实际页序和引用区域；不把模型猜测当成原因。
- 执行过程：查看运行编号、来源哈希、代码指纹、阶段时间线；新实时运行可看请求参数和检索决策。
- 报告导出：Markdown报告、JSON、CSV、六页Excel快照、日志和产物校验清单。

## 离线核验与回放

在项目目录终端中执行（将示例目录换为实际“执行过程”显示的运行目录）：

```powershell
.venv/Scripts/python.exe -m finance_agent.cli --verify output/运行目录
.venv/Scripts/python.exe -m finance_agent.cli --replay output/运行目录/result.json --output output/replay
```

回放读取原运行的已核验结构化金额和来源PDF，重新解析原文、补明细并执行当前程序计算；不读API配置、不调用模型、不覆盖原文件。它不是重新调用模型提取，也不声称逐个重审历史模型响应。若PDF哈希或原金额引用内容改变，拒绝回放。回放记录原运行编号、结果哈希及新旧代码指纹；代码升级后分析结论可能改变，须保留版本记录。

当前展示成果还保留history目录中的原始模型结果与日志，并在replay.model_history中列出运行编号、路径、哈希及请求/响应数量。伊利原提取有4次保存响应，公开样本两次原运行合计12次；本次重算没有新增调用。没有模型响应的重算日志不标成模型历史。复现时应同时保留来源PDF、history与artifacts.json；无需原电脑的绝对路径。

实时分析另行执行：

```powershell
.venv/Scripts/python.exe -m finance_agent.cli --files samples/某公司年度报告.pdf --output output/live
```

模型实际temperature、max_tokens、thinking等参数记入trace；接口不支持的seed不虚构。temperature=0不保证模型实时重跑逐字相同。模型响应和证据选择日志可用于审计。

## 预期结果与失败诊断

- 伊利2024/2025年报：非经常性税后归母合计分别为2,441,585,047.26元和496,844,802.69元。
- 同两期年报现金流调节表应分别还原21,739,740,393.38元和14,343,920,490.32元经营现金流，残差0元。
- 已有金额开发回归：伊利人工核对68个字段，六份公开样本34个字段；不是全报告字段准确率或独立测试准确率。
- 缺比较期间时显示需补报告；负基期和利润/现金流方向跨零不输出常规增长率。缺附注不认定无变化。
- 首次安装失败查看安装日志；分析失败查看trace的失败阶段、异常类型及脱敏堆栈。文件校验不符须重新取得完整运行成果，不能直接改清单掩盖差异。

## 环境与边界

本地解析和计算，实时模式只向配置的模型接口联网。文件访问、证据选择、输出和计算阶段由应用记录；本实现不是操作系统级文件沙箱。原始下载时间没有记录时明确标记未知，不能用mtime代替。

requirements.lock.txt锁定依赖版本，运行记录保存实际Python和包版本。当前尚未提供指定Python/系统架构的离线wheels及分发包哈希锁；联网首次安装不等于离线安装已验收。若赛方要求完全断网安装，需在确定评审环境后另准备对应依赖包。

实现含固定流程编排、工具契约目录、提取Prompt、实际加载的领域任务规范、解析/核验/计算/日志模块。当前以Web与CLI为入口，没有宣称已实现MCP服务。若评审指定MCP客户端，需要另实现和验收对应协议入口。

历史自检记录的9项、当前11项及六份/八份样本对应不同版本和范围。历史结果不改写；当前展示为六份公开样本加两份伊利年报。
