# 独立评测与人工标注

当前八份报告都参与过开发，应归为开发集。不能用已有34/34、68/68字段通过数宣称整体准确率。

## 组员需要做的工作

1. 选择未参与调试的新公司/期间，保留完整官方PDF及SHA256。
2. 在运行模型前，人工确认金额、单位、期间、合并/母公司、是否重述、来源页码；两人交叉核对。标注不能复制智能体答案。
3. 保存冻结时间、标注人、资料来源和本次代码指纹；保留人工标签版本。将新样本设为holdout。
4. 跑一次真实提取后，用评分程序比较。若继续据此改程序，这批样本转入开发集，最终测试另选报告。

## 标签格式

参考下列单条记录构造JSON。数字示例是格式说明，不能直接作为真实答案。没有人工答案时使用空列表，不会产生“100%通过”。

```json
{
  "dataset_role": "holdout",
  "frozen_at_utc": "人工实际冻结时间",
  "labelers": ["标注人", "复核人"],
  "fields": [{
    "match": {"company": "公司全称", "name": "revenue", "period_start": "2025-01-01", "period_end": "2025-12-31", "basis": "ytd", "scope": "consolidated"},
    "expected": {"value": "100000000.00", "currency": "CNY", "restated": false},
    "tolerance": "0.01",
    "accepted_citations": [{"document_id": "真实PDF哈希前16位", "pdf_page": 10}]
  }],
  "comparisons": [{
    "match": {"company": "公司全称", "metric": "revenue", "current_period_start": "2025-01-01", "period_end": "2025-12-31", "basis": "ytd", "scope": "consolidated", "kind": "yoy"},
    "expected": {"status": "ok", "current_value": "100000000.00", "base_value": "80000000.00", "delta": "20000000.00", "percent": "25.00"}
  }],
  "signals": [{
    "match": {"company": "公司全称", "period_end": "2025-12-31", "category": "nonrecurring"},
    "expected": {"status": "detected"}
  }]
}
```

信号类别：nonrecurring、accounting_change、cashflow_divergence。状态：detected、not_detected、insufficient_evidence。会计变化需据真实事件标注，不能把空白或未查范围标成“无变化”。

## 执行评分

```powershell
.venv/Scripts/python.exe -m finance_agent.evaluation --result output/运行目录/result.json --labels data/evaluation/人工标签.json --output output/evaluation/score.json
```

统计字段/计算/信号的标签一致率、匹配覆盖率、信号精确率和召回率及弃答率。真阳性被判为证据不足算漏检，不能从召回分母剔除。引用指标为人工接受的文档与页码定位命中率，不等同于整段引文语义正确率；更细语义标签需人工另行复核。无标签或无分母返回null，不返回100%。

评分程序无法证明样本独立性。独立性依赖冻结记录、人工答案来源与未参与调试的实际流程。
