# 伊利2024、2025年度报告新增测试

测试日期：2026年10月9日。组员提供伊利官网的两份完整年度报告：2024年报270页、2025年报259页，均为文字版PDF。

## 怎样测试

先从原始PDF独立抄录并逐页检查关键金额，再运行本机的真实DeepSeek流程。人工参考共68条：36条年度本期/基期金额、32条原文单季度金额；另核对18项年度同比和两个2025Q4扭亏状态。

原文样本保存于 `samples/member/yili/`，独立参考保存于 `output/yili_validation_20261009/manual_reference.json`。本次两轮真实提取共8次模型请求；修复后的原文重核、金额计算和页面切换不产生新请求。每轮原始输入输出分别保留，未用人工答案替代自动提取。

## 实测发现并修复的问题

- 年报的“2024年／2025年”金额列原先被拒绝为期间不明。现在必须同时确认封面、完整年度期间和本表上下文，才按全年处理；季度与半年不借用这个规则。
- 长年报检索被会计政策正文中的报表名称干扰。现在优先实际合并财务报表标题及明确续页。
- 模型仍可能写错表格行号。继续拒绝错误候选，再以已核验的同表收入、归母利润或资产总计为锚点，逐单元格补查原文现金流、资产、应收账款和存货。
- 原文季度摘要被漏提，趋势图也只从比较结果取点。现在四季原始金额须先与年度金额勾稽，再分别核验期间、单位和来源；图表同时读取已核验的原文单季记录。
- “会计差错更正不适用”不能误分类为会计估计变更；“期初未分配利润调整影响均为0”的固定列示不能单独证明发生当期会计变更。真实变更即使金额影响为0仍须保留。

## 信号效果与剩余缺口

- 2024非经常性损益占归母利润28.88%，触发当前项目的关注阈值；2025为4.30%，未触发。
- 2025合并利润同比增长而经营现金流下降，触发趋势背离线索。这个判断基于金额方向，不能自行断言财务问题的具体原因。
- 部分真实合并范围变动及2025现金流原因所在附注未进入模型检索范围。会计口径检查应保留证据不足，不能据此宣布未发生变化；也不把人工看到的其他事件填进自动结果冒充自动识别。
