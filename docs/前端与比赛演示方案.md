# 前端与比赛演示方案

2026年10月8日。第一版看板已完成并验证，下文保留选型与演示思路。实际入口、交互和讲解步骤见[看板演示指南](看板演示指南.md)。新界面只更新开发目录，组员正在使用的独立测试目录没有修改，本次界面开发没有调用API。

## 前端选择

建议继续采用Streamlit，用浏览器展示财务分析看板。Web描述展示方式，Python描述开发语言，两者不是互斥选项。当前app.py已经采用Streamlit，有文件上传、状态提示、指标表、证据文本、PDF页预览和下载，可直接迭代。

参考[Streamlit官方架构说明](https://docs.streamlit.io/develop/concepts/architecture/architecture)：Python服务端负责运行应用，浏览器作为客户端展示与交互。[官方布局组件](https://docs.streamlit.io/develop/api-reference/layout)支持侧栏、列、容器和标签页，能承载我们需要的看板。

|方案|适合的情况|本项目判断|
|---|---|---|
|Streamlit浏览器看板|Python分析项目，需要快速呈现指标、图表、证据和结果|当前优先方案，保留现有后端和启动方式|
|React或Vue网页前端，搭配Python服务|对布局、动画、复杂交互有明确需求，且愿意维护前后端接口|可作为后续升级，当前新增开发与部署工作较多|
|Python桌面窗口|需要独立桌面交互、离线工具等明确需求|当前项目以浏览器展示更方便，也已有可用入口|

第一版使用Streamlit布局、Altair季度图和少量样式调整，没有增加数据库、账号系统或新的前后端通信层。图表和金额卡读取已有核验结果。

## 看板设计

视觉上采用浅色底、深蓝主色，橙色表示关注信号，灰色表示证据不足。颜色配合文字标签，不能将未发现信号画成全面正常。宽屏布局用于录屏，普通电脑仍保留表格与文字说明。

1. **分析入口。** 上传多期报告或选择公开案例。真实API分析、已保存真实结果与虚构演示分别标记；处理进度依据程序实际事件展示，不生成虚假的百分比或倒计时。
2. **结果总览。** 公司和报告期间切换；四张金额卡展示营业收入、归母净利润、合并净利润和经营现金流。单位、累计/单季、报表口径始终可见。不同期间和口径的数字不能直接合并成一张卡。
3. **趋势与比较。** 华虹单季度收入、利润、现金流趋势；标注累计差分取得的季度值。不能将累计值与单季值混画，缺值不补零，负或近零基期保留专门说明。
4. **关注信号。** 将当前JSON细节改成可读金额、公式和披露说明。每条信号展示结论、输入金额、口径、判断条件、证据与待核对事项。页面同时列示发现、未发现和证据不足数量，不能只挑有信号的结果。
5. **原文核对。** 点击金额、信号或比较，跳到对应文件、引用及PDF物理页，并用橙色框标出引用区域。高亮可覆盖整段或整表，不代表精确单元格定位；预览不修改原PDF。
6. **成果导出。** 报告、指标表和运行记录入口保持可用。独立评测数据尚未形成，不在首页展示未经验证的准确率或风险评分。

## 五分钟视频建议

下表是建议讲解篇幅，不是程序运行速度承诺，也不是对后续赛程要求的再次核验。

|篇幅|画面|讲述重点|
|---|---|---|
|0:00—0:25|看板首页与业务流程|从多期财报到可核对的关注信号|
|0:25—1:00|一次真实分析的录屏|展示文件选择、实际执行进度和结果；等待剪辑或加速需要标明|
|1:00—2:10|华虹季度比较|半年累计减第一季度，取得第二季度，与第三季度按同口径比较|
|2:10—3:25|浪潮现金流及会计变化|关注结论、计算金额、采购付款原因、追溯调整原文|
|3:25—4:20|TCL合并与归母口径|归母盈利不能替代合并亏损；比例不适用时主动说明|
|4:20—5:00|原PDF和导出结果|证明结论能回到原文，并说明开发样本与独立评测的区别|

已保存真实结果可用于稳定讲解，但必须标记为回放。现场实时分析另外安排一次，并提前实测耗时、API可用性和报告规模。当前分析同步运行，不能承诺在同一次调用尚未完成时操作它的结果页。

## 三个现有真实案例

金额来自已保存并核验的output/20261003T122508Z_public_0b0c7447/result.json，以下以亿元展示，四舍五入仅用于讲解。

- **华虹2024三期财报：** 第二季度营业收入34.35亿元，第三季度37.70亿元，环比9.76%。重点是期间核验和累计差分。利润的大幅环比受较小基数影响，展示本期和基期金额。半年摘要附注缺失也应呈现。
- **浪潮信息2024三季报：** 前三季度合并净利润12.78亿元，经营现金流净额−93.87亿元，比例约−7.3432。展示采购付款原因及质保费用列报变化、比较期间重述。负现金流基期不输出普通增长率。原文原因是公司披露，不能冒充系统已经证明的完整因果解释。
- **TCL科技2024三季报：** 归母净利润15.25亿元，合并净利润−18.29亿元。现金转化比例规则不适用时说明口径；非经常性损益7.97亿元，占归母净利润绝对值52.23%，展示差额与披露总额核对。阈值关注信号不等于造假认定。
