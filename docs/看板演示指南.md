# 财报核验工作台：看板演示指南

2026年10月9日最新版采用森林绿主题，侧栏标识为“北京林业大学·创新者联盟队”。包含四家公司六份公开报告及伊利2024、2025两份完整年报，共八份公开财报的保存结果。独立测试目录和旧包不会自动更新；界面回放、切换筛选及原文预览不调用API。

利润／现金流跨零使用明确状态与变动额；页面和阅读报告默认亿元两位；TCL现金流基期恢复，同比36.28%。伊利年报期间识别、季度漏提和会计变更误报也已修复。详情见[反馈修复与图表说明](反馈修复与图表说明.md)和[伊利年报测试记录](伊利年报测试记录.md)。

## 打开

首次使用先完整解压、安装64位Python 3.13并双击“首次安装.cmd”；完成后双击“启动财报分析.cmd”，打开 `http://localhost:8501`。默认进入“成果展示”，无需API。保持启动窗口打开。

左侧“财报样本”切换“公开样本 · 4家公司”与“伊利 · 2024 / 2025年报”。选择会写入网址，刷新后继续显示该样本。组员可直接打开 `http://localhost:8501/?dataset=yili` 看伊利，`http://localhost:8501/?dataset=public` 看四家公司。开发预览使用 `http://127.0.0.1:8503`，组员普通启动入口为8501。

## 看板里能做什么

- 公司与报告截止日筛选；同公司同期多个文件共同保留，金额有冲突则留空。
- 营业收入、归母净利润、合并净利润、经营现金流四张金额卡；累计与单季分别选择，元、万元、亿元切换只改变显示。
- 单季度趋势及其计算来源。季度值来自已有程序核验结果，标记直接披露、第一季度等价或相邻累计差分。缺失与冲突金额不补零。
- “图表分析”提供不同利润口径和本期／基期金额图，沿用公司、期间、累计／单季及单位筛选，悬停显示期间和金额，按钮联动原文。
- 关注信号、已检查未发现和待核实数量同时展示。信号判断主要使用累计口径，切换单季金额卡不会重做单季信号判断。
- “关注信号”页面使用中文金额、公式、倍数、比例和披露说明，替代原先默认展示的JSON。
- 点击“核对金额”“查看原文”“定位季度依据”或“定位比较原文”，跳到对应文件和PDF物理页。橙色框是引用区域，可覆盖整段文字或整张表，不是精确金额单元格。预览不改写原PDF。
- “报告导出”可下载完整本次运行报告、表格、结构化结果和记录，包含当前样本组的所有公司；筛选只影响页面显示，两个样本组分别导出。

## 四个展示案例

### 1. 华虹：说明季度比较如何算

选择“华虹半导体有限公司”、2024-09-30。累计收入显示105.02亿元，切到单季显示37.70亿元；单季归母利润3.13亿元，单季合并净利润缺失则显示破折号。

季度趋势中一季度收入32.97亿元，二季度34.35亿元，三季度37.70亿元。展开“季度金额与计算来源”，查看二季度“相邻累计差分”，点击依据核对。到“期间比较”查看三季度收入环比9.76%，连同本期、基期、期间和来源一起展示。

不要将半年摘要缺失附注解释为没有异常；利润的大比例环比同时展示较小的基期金额。

### 2. 浪潮：从信号回到原因和会计披露

选择“浪潮电子信息产业股份有限公司”、2024-09-30、累计。合并净利润12.78亿元，经营现金流−93.87亿元。进入“关注信号”，查看现金流/利润−7.3432倍及采购付款原因，点击“查看原文”核对。

另查看质保费用改计主营业务成本和比较期间重述的披露。负现金流基期不展示普通增长率；原文给出的变化比例与程序的负基期处理分别说明。关注信号不是造假认定。

### 3. TCL：展示程序如何避免口径错误

选择“TCL科技集团股份有限公司”、2024-09-30、累计。归母净利润15.25亿元，合并净利润−18.29亿元；两者分别展示。现金转化比例规则因合并亏损而不适用，不用归母利润替代分母。

非经常性损益关注比例52.23%，在信号明细中展示归母与扣非差额、披露税后归母总额及依据。阈值是演示关注规则，不是监管标准。

在“图表分析”查看不同利润口径；经营现金流图比较本期220.01亿元与基期161.44亿元，同比36.28%。选择合并净利润，查看“由盈转亏”和减少73.97亿元，不展示常规增长率。原表少数股东损益−33.54亿元与归母利润相加可核对合并净利润。

### 4. 伊利：展示完整年报与季度趋势

在“成果展示”左侧“财报样本”选择“伊利 · 2024 / 2025年报”，截止日选择2025-12-31。累计营业收入1156.36亿元、归母净利润115.65亿元、合并净利润115.14亿元、经营现金流143.44亿元。营业收入与营业总收入分开，归母高于合并利润可由负少数股东损益核对。

趋势指标选择“归母净利润”，可看2024Q1至2025Q4八个原文季度金额。2024Q4亏损24.16亿元、2025Q4盈利11.39亿元；“期间比较”显示扭亏为盈和增加35.55亿元，不提供常规同比增长率。展开“季度金额与计算来源”，点击“定位季度依据”，核对PDF第8页。

“关注信号”显示2025利润增长与经营现金流下降的趋势线索；会计口径仍保留待核实。部分合并范围变动和2025现金流原因附注未被自动检索，不能把待核实解释为没有变化。

## 视频和现场展示

建议五分钟讲解：25秒介绍任务；35秒放一次真实分析录屏；45秒华虹；50秒浪潮；45秒TCL；60秒伊利；最后40秒展示原文与导出。时间是视频篇幅，不代表实时分析速度。等待剪辑或加速需要标注。

“成果展示”是已保存真实结果回放，明确标记，不冒充现场API调用。需要重新处理时，在本机 `.env` 填自己的DeepSeek官方密钥，重新启动后切到“真实财报分析”并上传材料；虚构流程检查用“演示模式”。每次最多6份、每份30MB、600页，只支持可复制文字的中文、人民币、中国会计准则PDF，扫描件尚无OCR。不要把开发样本核对或自动测试通过当作独立评测准确率。
