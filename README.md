# 财务报告异常信号识别智能体

这是比赛项目的第一版可运行原型：读取中文文字版财报 PDF，调用 DeepSeek 提取带原文引用的财务指标，交给 Python 核验金额、比较期间并检查三类关注信号。界面可以查看指标、期间比较、异常说明和原 PDF 页面。

第一版采用固定流程，提取后发现缺失或核验问题时最多补查一次。演示模式使用虚构数据，真实分析需要自己的 DeepSeek 官方 API 密钥。真实财报的准确率仍需要团队制作人工答案并测试。

2026年10月8日增加财务看板：默认“成果展示”直接打开已保存的六份真实样本，不调用API；可切换公司、报告截止日、累计/单季金额及展示单位。季度图使用已有核验结果，点击金额、信号或期间比较可定位原PDF页并框选引用区域。操作和比赛展示顺序见 [看板演示指南](docs/看板演示指南.md)。

## 先运行演示

在项目文件夹打开 PowerShell。当前电脑已创建 `.venv`；环境和依赖准备好后直接运行：

也可以双击项目中的“启动财报分析.cmd”。如果界面已经运行，直接打开浏览器页面即可。

```powershell
.\start.ps1
```

浏览器访问 <http://localhost:8501>，选择“演示模式”，点击“运行演示”。两份虚构企业年度 PDF 会自动生成，不需要 API，也不会产生模型调用费用。它们只用于检查流程，不能作为真实业绩或识别准确率证明。

也可以在终端运行：

```powershell
.\.venv\Scripts\python.exe -m finance_agent.cli --demo
```

如果这是第一次在另一台Windows电脑运行，先安装64位 Python 3.13（锁定依赖至少需要3.12），再双击“首次安装.cmd”，完成后双击“启动财报分析.cmd”。详细交接步骤见 [组员测试说明](组员测试说明.md)。也可以手动执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\start.ps1
```

`requirements.lock.txt` 记录这次开发环境实际安装的版本；`requirements.txt` 记录主要依赖的允许范围。若 PowerShell 阻止启动脚本，可以直接启动界面：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py --server.headless true --browser.gatherUsageStats false
```

## 配置 DeepSeek 官方 API

先把 `.env.example` 复制成 `.env`。复制只需做一次，之后直接编辑 `.env`，避免覆盖已经填写的密钥：

```powershell
if (-not (Test-Path -LiteralPath .env)) { Copy-Item -LiteralPath .env.example -Destination .env }
```

用本地编辑器打开 `.env`，把自己的密钥填在 `DEEPSEEK_API_KEY=` 后面，保留以下官方接口配置：

```dotenv
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
```

截至 2026 年 10 月 2 日，默认模型名称依据 [DeepSeek 官方模型说明](https://api-docs.deepseek.com/quick_start/pricing/)。模型可在 `.env` 修改，不写死在财务规则里。密钥不需要粘贴到聊天窗口；程序只从本地配置或同名环境变量读取，`.gitignore` 已排除 `.env`。

运行界面后选择“真实财报分析”，上传同一家公司的几份公开财报，点击“开始分析”。PDF 解析、金额运算和结果文件保存在本地，相关检索片段会发送给 DeepSeek，因此它是调用云端模型的应用。

真实模式也可以在“选择财报来源”中使用内置公开样本：华虹2024三期财报、TCL科技、科大讯飞、浪潮信息，或全部6份。华虹半年报使用摘要，合并净利润和附注覆盖有限；各样本来源、文件摘要及人工核对金额记录在 `samples/public/manifest.json`。这些是历史公开披露，不是虚构演示。

这台电脑已经保存六份公开样本的真实运行结果。选择“真实财报分析”，点击“查看已核对的6份样本结果（不调用API）”即可直接核对指标、期间比较、异常线索与PDF页面；点击“开始分析”才会重新调用模型。

完整6份真实测试运行后，可将本次 `result.json` 与人工答案比较；这一操作只读保存的结果，不再调用模型：

```powershell
.\.venv\Scripts\python.exe scripts/verify_public_examples.py --result ".\output\本次运行编号\result.json"
```

核对结果保存为同目录的 `public_check.md` 和 `public_check.json`，分别记录34个主要金额字段、4项华虹季度环比及项目规则结果。少量样本的核对通过不能换算成面向所有财报的准确率。

终端也可以分析文件：

```powershell
.\.venv\Scripts\python.exe -m finance_agent.cli --files "D:\财报\2024年报.pdf" "D:\财报\2025年报.pdf"
```

配置中的 `MAX_MODEL_CALLS=12` 限制每次分析的模型请求次数，失败重试也计入。文件较多时建议分批分析。账户余额、网络和官方模型可用性会影响真实分析。

## 运行后得到什么

每次运行保存到 `output/` 下的独立目录，界面也可以下载：

| 文件 | 用途 |
| --- | --- |
| `report.md` | 可阅读的分析报告 |
| `result.json` | 指标、比较、信号与证据的完整结构化结果 |
| `metrics.csv` | 便于人工核对的指标表 |
| `trace.jsonl` | 工具输入输出、模型请求结果与核验记录 |

来源引用的“PDF 第 N 页”始终指从 1 开始的 PDF 物理页序号。财报正文印刷的页码可能不同；核对时以 PDF 页序号为准。运行记录包含财报片段和模型输出，分享比赛材料时应同时核对这些内容的来源。

## 分析逻辑与边界

- 金额统一为人民币元，保留原始金额、单位、公司、期间、合并或母公司口径以及来源。
- 当前只处理中国会计准则数据；境外准则对照金额和外币金额会被拒绝。营业总收入存在独立营业收入分项时，不用总收入替代。
- 同比、环比由 Python 运算；先检查期间和口径是否可比。零、负或接近零基期以及盈亏／现金流方向跨零时显示专门状态，仅给增减金额。跨零时不展示常规增长率是本项目的呈现规则，不代表标准公式计算一定错误。
- 模型提取后再核查原表中的对比金额：列头须明确期间，并用已经核验的本期金额确认配对，随后核验基期的行列、单位与口径。不会由百分比反推基期金额。
- “缺少可比数据”表示未取得符合要求的基期金额，不表示该期间金额为零。例如第三季度环比需要第二季度单季金额，前三季度累计同比需要上年1至9月累计金额；上年度末余额不能充当上年第三季度末余额。
- 流量指标在口径可比时可以由累计金额推导单季度；资产、应收账款、存货等时点指标不会通过累计相减推导。
- 三类信号分别是非经常性损益影响、会计口径变化、利润与经营现金流背离。信号用于提出核对事项，不能直接证明舞弊。
- 缺少指标或披露时显示“证据不足”；“在已检查范围内未发现信号”仅说明当前材料和规则的检查结果。
- 同公司同期跨文件冲突、直接季度值与累计差分冲突时保留来源并停止计算。模型补查或批量调用中途失败时，尽量保存已核验结果，同时说明未完成范围。

当前支持可复制文本的中文 PDF，每次最多 6 份，每份最多 30 MB、600 页。暂未实现扫描件 OCR，复杂表格可能解析不完整。关键词检索只选取部分页面发送给模型，可能漏掉附注。程序可以检查引用存在、原始数值和口径形式，但仍需人工确认数字对应哪一列、单位是否正确以及披露语义。

当前指标与规则主要面向普通企业，金融行业特殊报表、外币财报及行业专属阈值需要后续适配。程序规则和模型提取共同决定结果，不应把演示样本的通过情况写成真实财报准确率。

已完成四家公司、六份公开财报的真实联调，再对保存的模型原始输出应用修复后的核验规则；34个主要金额、4项华虹季度环比和11项规则检查均通过。问题及剩余缺口见 [自查与真实样本扩充](docs/自查与真实样本扩充.md)，最初的单份季报记录保留在 [真实联调记录](docs/真实联调记录.md)。公开PDF样本在 `samples/public/`；它与演示模式的虚构PDF分开保存。
